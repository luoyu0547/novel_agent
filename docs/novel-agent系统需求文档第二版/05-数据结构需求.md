## 本页内容范围

定义第二版在需求层使用的数据结构、字段、状态及其用途；这些结构不等同于具体数据库实现。

## 结构关系

```text
Novel
├── NovelBlueprint
│   └── VolumeArc
│       └── ChapterPlan
│           └── ChapterBrief
│               ├── ContextPackage
│               └── WritingRun
│                   ├── DraftVersion
│                   └── ReviewIssue
├── Chapter
├── CharacterProfile
├── WorldSetting
├── PlotFact
├── Foreshadowing
└── PendingMemory
```

该关系图用于帮助理解需求对象之间的职责与流向，不限定最终数据库关系或基数。

## 数据结构明细

### 1. 已有数据结构继续保留

以下数据结构是第二版的支撑层，应继续保留并逐步增强：

| 数据结构 | 作用 |
|---|---|
| `Novel` | 小说项目基础信息、类型、风格指南 |
| `Chapter` | 章节标题、正文、摘要、状态 |
| `CharacterProfile` | 角色设定、动机、说话方式、行为边界、当前状态 |
| `WorldSetting` | 地理、势力、规则、历史、文化等设定 |
| `PlotFact` | 已确认的剧情事实 |
| `Foreshadowing` | 伏笔生命周期和风险提示 |
| `PendingMemory` | AI 提取结果的待确认区 |
