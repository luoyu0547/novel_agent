# 核心产品流程

> 第二版需求文档 · 第 4 部分（共 9 部分）

## 本页内容范围

从用户目标出发，说明新书启动、已有小说续写、单章自主写作和记忆回写四条端到端流程。

### 1. 新书启动流程

**目标**：从作者的初始构思形成可执行的小说规划，并完成第一章写作闭环。

**触发条件**：作者创建新小说，并提供类型、简介、风格和创作意图。

**核心流程**：

```text
创建小说项目
↓
填写类型、简介、风格指南和作者意图
↓
创建或导入基础角色、世界观设定
↓
整体规划 Agent 生成小说蓝图
↓
作者审核并确认蓝图
↓
整体规划 Agent 生成卷/篇章规划和章节大纲列表
↓
作者选择要开始写的章节
↓
章节规划 Agent 生成章节任务书
↓
写作 Agent 生成正文草稿
↓
检查 Agent 输出问题
↓
作者确认、编辑或要求重写
↓
确认后的正文触发记忆 Agent 提取
↓
作者确认 PendingMemory
↓
进入下一章
```

**主要产物**：小说蓝图、卷/篇章规划、章节大纲、章节任务书、正文草稿和记忆候选。

**作者确认点**：蓝图、正文草稿和 PendingMemory。

### 2. 已有小说续写流程

**目标**：把已有正文整理为可用于后续规划和续写的结构化上下文。

**触发条件**：小说已经有章节正文，作者希望从现有内容继续创作。

**核心流程**：

```text
导入或维护已有章节
↓
为已有章节生成摘要和剧情事实
↓
提取角色状态、世界设定和伏笔候选
↓
作者确认记忆
↓
整体规划 Agent 基于已有内容补全后续规划
↓
章节规划 Agent 生成下一章任务书
↓
写作 Agent 续写
```

**主要产物**：已有章节摘要、剧情事实、角色状态、伏笔候选、后续规划和下一章任务书。

**作者确认点**：从既有正文提取的记忆，以及 AI 补全的后续规划。

### 3. 单章自主写作流程

**目标**：在明确计划和上下文约束下，生成一章可检查、可处理的正文草稿。

**触发条件**：作者选择一个章节大纲或下一章目标。

**核心流程**：

```text
选择章节大纲
↓
生成章节任务书
↓
生成上下文包
↓
写作 Agent ReAct 执行
↓
输出章节草稿
↓
检查 Agent 评估
↓
作者处理草稿
```

**主要产物**：章节任务书、上下文包、Writing Run、正文草稿和检查结果。

**作者确认点**：作者决定接受、编辑、要求重写或废弃草稿。

### 4. 章节确认后的记忆回写流程

**目标**：把作者确认的正文转化为可追溯、可复用的长期创作记忆。

**触发条件**：章节正文已由作者确认。

**核心流程**：

```text
章节正文被作者确认
↓
记忆 Agent 提取结构化信息
↓
生成 PendingMemory
↓
作者逐条确认或拒绝
↓
正式写入角色、设定、剧情事实、伏笔
↓
后续规划和写作可检索使用
```

**主要产物**：PendingMemory，以及作者确认后写入的角色、设定、剧情事实和伏笔。

**作者确认点**：每条记忆候选都必须由作者确认或拒绝。
